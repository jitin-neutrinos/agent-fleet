# Neutrinos Icon Library

Official icon set - **thin lines + one solid accent shape**. Organized by
background and accent color. Each folder holds the same 63 icons.

```
on-light/blue    black lines + Neutrinos/Celeste blue fills   -> use on white / mist gray
on-light/green   black lines + Mint green fills               -> use on white / mist gray
on-dark/blue     white lines + blue fills                     -> use on Midnight/Neutrinos Blue
on-dark/green    white lines + Mint green fills               -> use on Midnight/Neutrinos Blue
```

Files are the original brand asset IDs (named `icon-<id>.png`) - transparent 4x PNGs.
Folder ordinals are NOT aligned with each other; always pick files through
`index.json`, which maps every concept to the correct file in each folder.

**Selecting an icon - no image previews needed.** Read `index.json`: match your
concept (or a tag, e.g. "insurance", "analytics", "security") and use the file
listed for your chosen folder. Example: a shield lock on a light background with
blue accent is `on-light/blue/icon-4371.png`.

**Usage rules** (see `../../references/photography-and-icons.md`):
- Pick the one folder that matches your background and your single accent color.
- Use icons from that folder only, so the accent stays consistent.
- Never mix two accent colors in one layout.
- Need an icon that isn't here? Draw it in the same style (thin line + one solid
  accent shape) rather than importing an off-style icon.
