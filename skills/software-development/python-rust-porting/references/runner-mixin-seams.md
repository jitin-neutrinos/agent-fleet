# Porting `run_*` / mixin modules that reach through a live runner or adapter

The gateway phase files (`gateway/run_*.py`) are functions and mixins that take a live `runner` or adapter and reach through it. Port the DECISIONS as plain logic over trait seams; drive the REAL module in the golden with a `SimpleNamespace` host whose every reach-through logs itself. The contract is three things, all compared: the return value, the ORDERED host-call log, and the captured log records.

| Python shape | Rust shape | Golden does |
|---|---|---|
| `runner.x(...)`, `adapter.x(...)` | method on a host trait | fake appends `[name, args]` to a call log |
| `getattr(o, "a", None)` then `callable(...)` | seam method returning `Option<_>`; `None` = absent or not callable | omit the attribute / set a non-callable |
| truthiness-tested attribute (`message_id`, `raw_message`) | raw `serde_json::Value` + `py_truthy`, not `Option<String>` | feed `0`, `""`, `[]`, `{}`, `"0"`, `True` |
| `type(adapter).m is not Base.m` | `overrides_m()` on the adapter seam | classes with and without the override |
| `await runner._run_in_executor_with_context(fn)` | plain call — the thread hop has no semantics | log `["hop"]`, strip it from both sides before comparing |
| `with scope(home):` | guard with a fallible `exit()`; order enter, body, exit | scopes whose enter / exit raise |
| `for x in runner._gen():` (lazy generator) | boxed `Iterator` seam, consumed lazily | log each `yield`; an early `return` must leave later items unproduced |
| `logger.warning/debug(...)` as a branch's only effect | `LogSink` seam receiving `(level, message)` | `logging.Handler` on the reference logger; normalise exception text to `<exc>` |
| `except Exception:` swallow | `Result<_, PyExc>` carrying the class name | raising fakes; the class matters only where a caller branches on it |
| `time.monotonic()` + `stop_event.wait(t)` loops | `Monotonic` + `StopEvent` traits | fake clock advances by each requested wait; log every wait value |
| module constant read at call time | injectable parameter, constant as default | patch `mod.CONST = x` per scenario so both branches are provable |
| `Path` as key / `dict.fromkeys(Path(..))` | normalised key (python-stdlib-semantics.md) | spellings: trailing slash, `.`, `//`, relative |
| `os.stat` stamps | `Fs` seam returning `(mtime_ns, size)` | real files, `os.utime(ns=...)`, root tokenised in outputs |
| `getattr(type(adapter), "_m", None)` (CLASS lookup) | method on the adapter CLASS; a per-instance `__getattr__` cannot answer it | a real subclass carrying the method, vs one without |
| `int(x)` applied to an id before the call | the SEAM raises `PyExc` before any call is recorded | non-numeric ids, so the raise arm is observable |
| `logger.info("x=%r", v)` | `LogSink`; `%r` ALREADY renders quotes | compare the log record, or a doubled-quote port looks identical on return values alone |
| guard kwargs (`**rename_kwargs`) | a typed guard enum | compare the kwarg VALUES, not just that a call happened |
| `is _SENTINEL` on a module-level sentinel | a dedicated token type (never text equality) | a real sentinel AND a look-alike string, so identity is distinguishable from equality |
| a SUPPRESSED raise (`with _log_suppressed(DEBUG, …)`) | `Result` whose error you LOG at that level, then continue | a raising seam, so the record is the only proof the arm ran |
| `isinstance(v, str)` guard on a seam-supplied value | the seam carries the RAW wire value, not `Option<String>` | a truthy non-string (the Mock shape) alongside the string |
| a sync store behind an async facade (`db = self._session_db` then `await db.m()`) | one seam for the async surface, one for the unwrapped raw object | the raw db methods are synchronous; an async fake makes every `if not handle` guard see a truthy coroutine |

Rules

- Run the module's own tests first (they must pass in this tree) and mine them for scenarios, then add the hostile cases they never had: raising seams, falsy raw values, empty inputs, missing attributes.
- Seam call ORDER is contract — a sweep that probes homes in order and stops at the first active one, a lazy iterator that stops early. Log it; never assume it.
- **Assert the reference's OWN method still answers after you wire the host.** A host that defines a method the reference also defines shadows it, the real code never runs, and every scenario passes for the wrong reason. Check `mix.<m> is not host.<m>` for each name both define, and delete the host's copy.
- **Verify every probe name the fake must answer, character for character.** `getattr(adapter, "_create_dm_topic", None)` is underscore-prefixed; a fake exposing `create_dm_topic` answers None and the method silently skips. `__getattr__` fires only for MISSING attributes and does not run for names set in `__init__` — store such attributes in `__dict__` directly.
- Port what the awaited function decides, not asyncio plumbing, loops or thread pools.
- A branch dead by a constant (a TTL that is always 3600) needs the injectable parameter, or the mutation check can never kill a mutant there.
- **A branch whose guard is unreachable from every scenario is not covered — it is untested.** The mutation check is what tells you: a surviving mutant on that branch means no input reaches it. Find the input that does (often a value the reference coerces but your fixture treats as falsy) and probe the real reference to confirm the line runs.

## Ordering the SEAM work, and what the harness gets wrong

- **Size the layer off the reference's own method list, not an estimate.** Enumerate every `def` in the class with its line span before splitting a god-file into layers; a "roughly N methods" estimate made the previous split wrong in both directions. Split by DEPENDENCY, not by size: pure/config/formatting first, then the seam-driven cluster, then the orchestration phases that consume both.
- **Give each seam-cluster row its OWN harness triplet** (`gen_<area>_l2a_golden.py`, `<area>_parity_run.rs`, `compare_<area>.py`, `mutation_check_<area>.py`) plus its own campaign gates. Reusing the previous layer's comparator means the two suites collide on one answers file and neither is readable.
- **Put a reach-through on the seam the REFERENCE reaches through.** A method the reference calls as `adapter.cancel_background_tasks()` belongs on the ADAPTER trait, not the runner trait — modelling it on the runner invents a call the reference never makes and corrupts the ordered log.
- **Keep port-internal steps OUT of the ordered call log.** The log is the reference's own call sequence. An `asyncio.shield`, a thread hop, and a plain `getattr` are steps the port takes, not calls the reference makes; recording them makes the port's log diverge for reasons unrelated to behaviour.
- **A `getattr(type(x), "m", None)` probe returns the UNBOUND function.** Call it bound (`resolver(x, arg)`) or every row in that section raises `TypeError` and reports your harness bug instead of the port's. And an ABSENT method is not a call either — it must not appear in the log at all, or a "never reaches the resolver" row is indistinguishable from "resolves to None".
- **The logger a module uses is not the module's own name.** A file can `logging.getLogger("gateway.run")` while living in `gateway/run_startup.py`; a handler attached to the guessed name captures nothing, every log row comes back empty, and it reads as a port that forgot to log. Grep the file's own `getLogger(` line, and attach to every logger it names.
- **A dict lookup keyed on an ENUM never matches a string-keyed fake — every row then silently takes the wrong branch.** `self.adapters.get(platform)` where `platform` came from `Platform(row["platform"])` looks up an enum MEMBER; a fake whose map is keyed by strings returns `None` for every row, so the whole section exercises the "adapter vanished" arm and every other arm goes untested. The symptom is a section where most rows produce the same answer. Key the fake by the enum, or by the enum's `.value` on BOTH sides, and keep one row per arm so a uniform result is visibly wrong.
- **A helper the reference calls WITHOUT `await` must be SYNC in the fake — an `async def` fake returns a coroutine, which is truthy.** This makes the guard it feeds always pass and the branch behind it permanently unreachable: a `profile`-keyed row always "found" an adapter, so the release-on-vanished-adapter arm never ran across ten rows. A `RuntimeWarning: coroutine ... was never awaited` in the golden's stderr is the tell. Make the fake sync, and assert the arm you meant to test is actually reached.
- **A golden row that leaves the REAL dependency in place is machine-dependent.** A display-strip variant initially ran with the real filesystem validator still bound, so its answer depended on whether this host happened to have the file. Pin it to a canned answer inside the scenario; that immediately exposed that the port was calling the wrong variant of the helper.
- **A shared module-level list in the golden accumulates across rows unless you SNAPSHOT it into the spec.** `S(..., {"written": _written})` records the LAST row's value for every row, because the dict holds the reference. Copy with `list(_written)` at record time.
- **A `@staticmethod` the reference calls on the CLASS must be invoked without `self`.** Passing the host as the first positional makes it the first declared parameter, so an explicit keyword argument on the same signature raises `TypeError: got multiple values for argument`. Check the decorator above the `def` before wiring a call.
- **A predicate that is a NAME LIST in your port is usually a SUFFIX or membership RULE in the reference.** A conflict test was ported as three hard-coded error names; the real body is `code.strip().lower()` then `== "lock_conflict" or code.endswith("_lock")`. A name list misses every code the family actually emits, and the miss routed a lock conflict down the RETRY branch — the gateway would start deaf instead of exiting 78. When a boolean reads as a list of literals in the reference, print its body and port the operation, not the enumeration.
- **A constant you PARAPHRASE can render in output a human reads — measure it and import it rather than re-declaring it.** A recovered-reply marker was guessed as a short tag; the real value is a long user-visible string an earlier row's generator already emits. Guessing prepends the WRONG TEXT in production while every unit test still passes. Search the crate for an existing generated constant before writing a literal, and read the reference's line for the exact bytes.
- **Record the ORDERING side effects a ladder performs, not just its return value.** When one rung of a dispatch delegates to a shared helper that also mutates shared state (a status record, an error list), calling the status setter inline instead drops the message that the helper wrote. Give each rung its own helper, port the DELEGATION, and let the shared helper's own effects be the thing you assert.
- **The reference's fakes are OBJECTS, not dicts, when the code does attribute access.** `dest.handoff_config.platforms.get(k)` reads an ATTRIBUTE holding a mapping; a plain-dict stand-in raises `AttributeError` on `.platforms` and the row diff looks like a port bug. Build nested objects (or `SimpleNamespace`) to the depth the reference actually reaches.
- **Carry every INPUT in the spec, in a shape the runner can replay.** A spec holding `repr(source)` or a store *kind* cannot be re-driven, so the runner either guesses or rebuilds the value — which is exactly how a replay runner becomes a second implementation. Put the plain-JSON source shape, the scripted outcome list, and any sentinel token in the spec; assert each row's spec is self-sufficient.
- **When a comparator's first run shows dozens of shape diffs (`MISSING-RUST`/`MISSING-GOLDEN` pairs), the SHAPE is the bug, not the behaviour.** Pick ONE shape per field, apply it to both sides, and re-run before touching the port. Iterating one field at a time across a five-field mismatch set is the slow path; a single decision per field resolves it in one pass.
- **Rebuild and re-point every mutant anchor after moving a seam method.** A gate whose anchors still reference the old signature reports `anchor matched 0x` or `does not compile`, and a broken mutant is NOT evidence — the denominator shrinks silently. Re-run the anchor pre-flight (count `src.count(old) == 1` for every mutant) before spending a rebuild loop on a gate you have not verified can fail.
- **Write multi-line anchors as triple-quoted raw strings, and a comma inside one does not end the tuple.** An anchor entry missing its label parses as a 2-tuple and the pre-flight's `for l, o, n in MUTANTS` raises mid-list, so later anchors are never checked at all.
- **A probe that reads a MODULE global is not a host seam — the row is a no-op unless the module attribute is removed.** `getattr(signal, "SIGUSR2", None)` is how the reference decides whether the POSIX-only hook runs; a fake that only sets a host flag leaves the real `signal` module bound, so the "Windows-shaped" row installs a hook and the flag never mattered. Delete the module attribute for that row and restore it in the `finally`. Same shape as the class-lookup and `getattr`-default rules, one level out.
- **A fake must satisfy the real API's ARGUMENT TYPE, or a suppression block hides the mismatch as a log record.** `asyncio.create_task` rejects a non-coroutine with `TypeError`, and a `_log_suppressed` around the call converts that into a DEBUG plus skipped work below — so the row looks exercised while it proves nothing. A fake that returns a plain object where the reference expects an enum, a mapping, or a coroutine has the same effect. When a golden row shows a suppression record nobody expected, suspect the fake's return type before the port.
- **Give a boolean-returning seam BOTH answers as separate rows.** A fake whose `register()` returns `True` or raises has no `False` arm, so the "not registered / no URL" branch is untested and a mutant that proceeds anyway survives — the arm looked covered because the happy path exercised the same function. Any seam returning `bool`, `Option`, or a sentinel needs one row per answer, and the golden's spec must carry which one the row wants.
- **Python evaluates a call's arguments BEFORE the call, so an argument with side effects appears EARLIER in the ordered log.** `enable(file=self._open_faulthandler_log())` opens the log first; modelling the two as independent calls in the other order yields a different trace with identical behaviour. When an ordered-log diff is only two adjacent entries swapped, check evaluation order before suspecting a branch bug.
- **A NESTED suppression block logs ONCE, not once per level.** `except: with _log_suppressed(MSG): try: … except: pass` produces a single record for the outer failure; the inner block's own failure is caught by the same `except`. A port that re-logs per level invents a record the reference never emits, and the diff is a repeated message — count the `try/except` blocks, not the operations.
- **A stdlib-backed seam that takes a CONSTANT needs the constant measured and unit-tested.** A watchdog probe interval guessed at a fifth of the real value keeps parity green (no row asserts on elapsed time) while changing how long a frozen loop goes unnoticed. Print the constant set from the live module in one probe before writing the Rust consts, import it from an existing generated table when the project already has one, and assert the measured value in a unit test.
